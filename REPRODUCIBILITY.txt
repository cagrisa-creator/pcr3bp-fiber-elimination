SCIENTIFIC SCOPE
----------------
The algebraic identities and geometric reconstruction are exact. The numerical
data are finite floating-point samples. NO fixed parameter pair or parameter
region in this package has an interval numerical convexity certificate. No
interval-certified non-convexity witness, continuous mass threshold, shell
theorem, limiting-value theorem or dynamical-convexity theorem is supplied.
Positive samples do not establish positivity between samples. An 80-digit
evaluation is a precision cross-check, not an interval enclosure.

The API/CSV field D_true_min is retained for backward compatibility. It means
the sampled estimate of the fiber minimum, not an exact continuous minimum.
mu is the DISTANT-primary mass fraction; m_r=1-mu is the regularized-primary
fraction. c is half the Jacobi constant; Delta c=c-c_L1(mu) is computed using
a floating-point critical value, without a parameter-dependent enclosure.

RUN EXACT SYMBOLIC CHECKS
------------------------
Run from the snapshot root:

  python code/fiber_elimination_audit.py
  python code/rotation_term_audit.py
  python audit/verify_gates_cache.py
  python audit/criterion_symbolic_audit.py

Expected: PASS_C82_FIBER_ELIMINATION_AUDIT (8 zero residuals),
PASS_ROTATION_TERM_AUDIT (zero symbolic residual plus numerical spot checks),
PASS_GATES_CACHE (6 zero residuals), and
PASS_GEOMETRIC_CRITERION_RECONSTRUCTION (23 exact checks).
Measured on the preparation host: about 1.5 s, 4.4 s and 173 s respectively
for the first three original scripts. SymPy build time is machine-dependent.
The rotation script also checks 200,000 points; maximum observed deviation
was 4.263e-14. This numerical portion is distinct from its exact residual.

REPRODUCE THE REVISED FIGURES AND DIAGNOSTICS
------------------------------------------
From code/:

  python convexity_map.py
  python phase_map_figure.py
  python audit_figures.py
  python refine_lobes.py
  python lobe_structure.py

convexity_map.py writes ../results/phase_map_data.csv. phase_map_figure.py
uses that CSV. audit_figures.py writes Figures 2-3 to ../paper/figures and
their complete plotted data to ../results/figure_audit. Its measured numerical
run is approximately 3 seconds after imports. refine_lobes.py compares the
recorded 200x80x192 lobe grid with 400x160x768 at three selected masses.
lobe_structure.py retains the five-mass diagnostic whose endpoint values
are cited in the article. The Figure 3 generator additionally records all
13 masses mu=.20,.25,...,.80; its ray panel uses 160 radial samples.

For the complete historical-versus-revised audit, run from the snapshot root:

  python audit/audit_parameters.py --source frozen_inputs/code --reference frozen_inputs/results/phase_map_data.csv --corrected-source code --output results/parameter_audit --suite all
  python audit/heavy_side_check.py
  python audit/high_precision_witnesses.py

The original and revised directories must remain distinct: the historical
comparison intentionally preserves the old boundary-NaN behavior. Running
the full audit overwrites numerical output files, not source files. An
individual suite may be selected: phase, critical, spot, corrected, threshold,
or witnesses. The corrected suite requires phase/critical outputs first;
witnesses should be run last. Full reproduction takes several minutes to
tens of minutes depending on the host. Recorded examples: the 112-pair
historical phase suite took 88 s, and the dedicated 600x400x1024 mass-transition
study with 12 numerical mass-bisection steps took 287 s.

WHAT CHANGED IN THE NUMERICAL CODE
----------------------------------
1. Figure 2 used theta modulo pi/2 for both its full-plane boundary and its
   point construction. That applies quarter-turns where reflections are
   required. Its complete generator now uses the physical ray angle.
2. Numerically located collar roots can have tiny negative F residuals.
   The revised global/lunar routines evaluate the nonsingular F=0 formulas
   on the last radial row. Interior samples are not clamped or changed.
   This removes 1719 omitted boundary samples across the 112 old map cases.
   Some sampled extrema change, but no map sign classification changes.
3. The lunar script reuses the already-audited coefficient cache instead of
   constructing a duplicate symbolic determinant. The formulas, grids and
   candidate selection remain unchanged.
4. Figure generators/diagnostic wording consistently distinguish sampled
   minima from exact minima, avoid unsupported orbit identification, and
   use 'one negative direction' instead of singularity-theory terminology.

There is no interval-certification subpackage because no such certificate
is claimed. Frozen source checksums are preserved for provenance; any
ORIGINAL_FULL_TREE_MANIFEST_REFERENCE.txt refers to the older full repository,
of which only relevant scientific files are included here. The new root
SHA256SUMS_R07.txt is the complete manifest for this supplied snapshot.
