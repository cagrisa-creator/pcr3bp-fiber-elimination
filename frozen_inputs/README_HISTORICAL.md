# Historical comparison inputs

This directory preserves earlier code, data, metadata and logs unchanged for
the historical-versus-revised comparisons documented in the root
`REPRODUCIBILITY.txt`. It is not a set of current generators or current expected
outputs. Do not run its old figure scripts as replacements for the revised
generators in the root `code/` directory.

In particular, old logs and source comments can contain "simple fold",
"intrinsic to the limit", "Non-convex shell", or orbit-related axis labels.
Those expressions are retained only as historical evidence; the current
manuscript withdrew the corresponding stronger interpretations. They do not
assert an interval certificate, a limiting-value theorem, an orbit-axis
identification, or a singularity-theoretic normal form in the revised work.

Current result locations are indexed in `../results/README_CURRENT.md`.
The historical audit intentionally uses this directory's code and reference
CSV. These input files have not been changed by the R07 editorial corrections.
