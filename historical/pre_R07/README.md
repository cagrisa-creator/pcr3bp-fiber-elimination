# Historical outputs retained before R07

The files in `results/` below this directory are verbatim legacy outputs and
their original environment/manifest records. They are preserved for provenance,
not presented as current output or expected output of the revised manuscript.

The legacy logs include terminology that the current manuscript withdrew:
"intrinsic to the limit", "Non-convex shell", "simple fold", and descriptions
identifying base axes with particular orbits. Such wording is historical and
must not be read as a current mathematical, dynamical, or interval-certified
claim. The legacy numbers can also reflect earlier grids or execution details;
the text of an old log has not been rewritten to imply a new computation.

The accompanying `RUN_ENV.txt` identifies the environment of those older logs.
The `SHA256SUMS` file is the original full-repository manifest: its paths and
hashes describe that historical tree, not this directory or the current archive.
For the current archive, use the current root manifest supplied with it.

Current evidence and its scope are indexed in `../../results/README_CURRENT.md`
relative to this directory, and in the root `REPRODUCIBILITY.txt`. No numerical
calculation, figure, mathematical proof, or recorded current data was changed
when these old files were separated from current results.
